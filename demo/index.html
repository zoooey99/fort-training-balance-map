Ranges show how your workload adds up.

Action floor
  • Three sets below the productive range
  • Another session may be useful soon
  • Separates “below target” from “I need to train immediately”
Productive range
  • 10–20 effective sets of recent work
  • A useful range, not a score to maximize
  • Leaves room for different routines and preferences
Above range
  • More work on the same pattern may not be useful yet
  • Makes recovery visible without prescribing an exact rest day

A workout becomes effective sets by pattern.

Each working set counts fully toward its primary pattern. Secondary patterns can receive additional partial credit, so pattern contributions do not need to sum back to the workout’s physical set count.
